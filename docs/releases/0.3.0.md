Drop & View Render 0.3.0 for Apple Silicon Macs (macOS 14 or later).

- Send a scene from Drop & View in Safari through the embedded Safari extension.
- DENOISE and ADAPTIVE can be controlled independently in the web render panel;
  each queued scene retains its accepted settings and requested render targets.
- Serial render queue, cancellation, progress/time and numbered PNG outputs.
- Manual GLB and .dvrender opening and View in Blender remain available.

Install stable **Blender 5.3.0** separately. Download the macOS-arm64 DMG, drag the app
into Applications, launch it, then enable Drop & View Render in Safari Settings
→ Extensions and grant access to the Drop & View website. Reload the website and
use CONNECT in the RENDER panel. Keep the native app running during rendering.

Blender and a separate Python runtime are not bundled. Chrome/Edge still require
the separate developer-mode extension setup. Windows remains a separate prototype.
SHA256SUMS.txt accompanies the DMG.


## Windows 11 x64 prototype

**Recommended for normal installation:** download **DropViewRender-Windows-0.3.0-Setup.exe** below.
It installs the tray app and registers its browser connection for your user account.

**Optional portable version:** **DropViewRender-win-x64.zip** contains the same app
without an installer; extract it and run Register-Browsers.ps1 manually.
You only need **one** of these downloads, not both.

Install stable Blender **5.3.0** separately. The companion runs as a tray app; Chrome/Edge supply the scene controls.
The browser extension still requires Developer mode → Load unpacked from the
installed ChromiumExtension folder.

These Windows builds are **unsigned prototypes**. Automated Windows build, native
host/process-ownership tests and installer packaging passed; real Windows 11
browser/GPU render acceptance is still pending. Denoise and adaptive sampling are
currently always ON in the Windows renderer; independent OFF switches are not yet
supported. Windows-SHA256SUMS.txt covers both Windows assets.

Windows binaries were built from commit `6c1bf788cbe92248ed8cb70f7a73407b33c63792`
(including the Blender 5.3 update) by the
[successful Windows workflow](https://github.com/hildgyorgy/drop-view-render/actions/runs/43317347537).
The existing macOS artifact remains the original release build.
